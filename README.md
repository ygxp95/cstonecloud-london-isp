**坑1：把"双ISP"和"原生IP"混为一谈**

双ISP强调的是IP注册信息挂在两个真实ISP名下，原生IP强调的是IP归属地和机房所在地一致。两者经常同时出现但不完全等同。下单前最好自己查一下IP的 ASN 和 fraud score，别只看商家宣传词。

**坑2：忽视"国际BGP不保证国内方向稳定性"这条说明**

CstoneCloud 官网对英国线明确写了这句话。意思是：从英国本土访问没问题，但从国内直连可能丢包、绕路。如果你的业务是国内用户访问英国内容（比如建站给国内人看），要么自备中转，要么换带CN2 GIA优化的线路。

UK-ISP-A 是 300Mbps/2TB，UK-ISP-D 是 500Mbps/16TB。看起来D流量多8倍，但如果你只是看剧，A的2TB一个月根本用不完；如果你是做视频搬运、爬虫，D的500M带宽才更能发挥价值。按用途选，别只盯着流量数字。
